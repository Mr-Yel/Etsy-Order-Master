# 2026-10-12

## 导出商品图（Thumbnail URL）尺寸从 75×75 改为 350×350
- 背景：Excel 导出末列 `Thumbnail URL` 取的是订单列表接口的商品缩略图，Etsy 只返回 75×75。
- 字段来源：`orders[].transactions[].product.image_url_75x75`（Orders_OrdersCollection 列表接口）。
- 关键结论：Etsy 图片 CDN 的 URL 尺寸段 `il_{宽}x{高}` 支持任意值（`il_75x75` → `il_350x350`，原图用 `il_fullxfull`），换尺寸无需重新请求接口。
- 改动文件：
  - `utils/orders-mapping.ts`：新增 `THUMBNAIL_IMAGE_SIZE = "350x350"` 常量与 `toEtsyImageSize(url, size)` 工具函数（先按 `/(_\d+x\d+)(?=\.)/` 替换，失败再全局替换 `75x75`）；`Thumbnail URL` 输出改为 `toEtsyImageSize(transaction.product?.image_url_75x75, THUMBNAIL_IMAGE_SIZE)`。
  - `etsy-order-api-fields-mapping.md`、`etsy-order-required-fields.md`：补录 `Thumbnail URL` 字段来源与 350×350 改写规则。
- 影响面：`Thumbnail URL` 唯一产出点就是 orders-mapping.ts，Excel/CSV 导出（OrderExportModal.vue、entrypoints/content.ts、lib/kst-order-sync.ts）共用，改一处全生效。
- 注意：`OrderImageExportModal.vue`（图包 ZIP 导出）是独立功能，预览仍用 75×75、下载用 1000×1000，未改动。
- 校验：`vue-tsc --noEmit` 无 orders-mapping 相关错误（lib/kst-proxy-* 的报错是既有的）。
- 用户澄清范围：**只改 Excel 导出那个字段，其他地方一律不动**。「订单图片导出」弹窗（OrderImageExportModal.vue）的 75×75 预览与 1000×1000 下载都保持原样，不要改成 350。
